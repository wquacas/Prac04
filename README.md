Наблюдение для отчёта: Нагрузка в основном сосредоточена на одном логическом процессоре. 100%/4 = 25%. Она может выглядеть небольшой, потому что другие логические процессоры свободны.

Вывод: Эксперимент показал, что нагрузка сосредоточена на одном логическом ядре, предположение подтвердились.
